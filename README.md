# Paradise Nursery 🌿

**Paradise Nursery** — интернет-магазин комнатных растений на React.

Приложение позволяет просматривать каталог растений по категориям, добавлять
их в корзину покупок, изменять количество и удалять товары, а также видеть
общую стоимость заказа в реальном времени.

## Возможности

- Страница приземления (landing page) с названием компании и кнопкой «Начать»
- Раздел «О нас» с информацией о компании
- Каталог из 18 комнатных растений в трёх категориях
- Навигационная панель со ссылками «Главная», «Растения», «Корзина»
- Иконка корзины с динамическим счётчиком товаров
- Корзина со счётом общей суммы, изменением количества и удалением товаров
- Кнопки «Оформить заказ» и «Продолжить покупки»

## Технологии

- React
- Redux Toolkit + React Redux
- React Router
- Vite
- CSS

## Запуск проекта

```bash
npm install
npm run dev
```

## Структура проекта

```
src/
  App.jsx                 — приземлённая страница и маршруты
  App.css                 — стили, фон приземлённой страницы
  components/
    AboutUs.jsx           — информация о компании
    Navbar.jsx            — навигационная панель со счётчиком корзины
    ProductList.jsx       — каталог растений по категориям
    CartItem.jsx          — страница корзины покупок
  redux/
    CartSlice.jsx         — Redux-срез корзины
    store.js              — хранилище Redux
  main.jsx                — точка входа
```
